# F5GO OpenWRT Proxmox VE Installer 🚀

Универсальный инструмент для автоматизированного развертывания OpenWrt в среде Proxmox VE. Скрипт предназначен для создания высокопроизводительных роутеров с использованием аппаратного проброса сетевых контроллеров (PCI Passthrough).

---

## 🎯 Основная концепция

Этот скрипт подготавливает гипервизор и виртуальную машину для работы в режиме **Hardware Passthrough**. 

- **Цель:** Использование физических сетевых портов (NIC) напрямую в OpenWrt для минимизации задержек и нагрузки на CPU.
- **Сетевая архитектура:** Скрипт настраивает систему для проброса реальных LAN/WAN портов. Работа с виртуальными VLAN внутри Linux Bridge не является приоритетом данного инструмента.

---

## ✨ Возможности

*   **Настройка IOMMU (Passthrough):**
    *   Автоматическое определение CPU (Intel VT-d / AMD-Vi).
    *   Поддержка загрузчиков **GRUB** и **systemd-boot** (ZFS).
    *   Активация необходимых модулей ядра (`vfio`).
*   **Умная установка OpenWrt:**
    *   Автоматический поиск последней стабильной версии.
    *   Проверка целостности образа по **SHA256**.
    *   Гибкая настройка ресурсов: RAM и ROM (диск автоматически расширяется).
*   **Автоматизация:**
    *   **Safe Self-Destruct:** После завершения работы скрипт удаляет временные файлы и самого себя.

## 🚀 Быстрый запуск

Выполните команду на ноде Proxmox под пользователем `root`:

```bash
wget -qO f5go-openwrt-install.sh https://raw.githubusercontent.com/F5GO/F5GO-OpenWRT-Proxmox-VE-Installer/main/f5go-openwrt-install.sh && bash f5go-openwrt-install.sh
```


> [!CAUTION]
> **Важно:** Запуск напрямую через `curl | bash` заблокирован. Скрипту необходимо находиться в файловой системе как физический файл для корректной настройки службы автопродолжения после перезагрузки.

## ⚙️ Что нужно сделать вручную?

Скрипт выполняет **90% технической настройки**, но назначение конкретных физических портов требует вашего участия, так как PCI-адреса устройств уникальны для каждого сервера.

**После завершения работы скрипта:**

1.  Зайдите в Web-интерфейс **Proxmox**.
2.  Выберите созданную виртуальную машину (**OpenWrt**) → вкладка **Hardware**.
3.  Нажмите `Add` → `PCI Device`.
4.  В появившемся окне выберите режим **Raw Device** и найдите в списке ваш сетевой контроллер (физический порт, который станет WAN или LAN).
5.  Обязательно включите опции **All Functions** и **ROM-Bar**.
6.  Запустите VM.

## 🛠 Технические требования

*   **Proxmox VE:** Версия 7.x или 8.x.
*   **Процессор:** Поддержка виртуализации в BIOS (**VT-d** для Intel или **AMD-Vi** для AMD должна быть включена).
*   **Хранилище:** Минимум **512МБ** свободного места на целевом storage.
